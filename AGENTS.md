# AGENTS.md

Архитектурная документация проекта. Источник истины для AI-скиллов, которые пишут код.
Полные промпты и пошаговые инструкции для каждой роли находятся в `.claude/commands/`.

## 1. Project Overview

Интерактивная платформа для изучения английского языка через фрагменты фильмов и сериалов
(например, "Silicon Valley"). Урок — это лендинг-страница, собранная из JSON-описания секций,
с embedded-модулями: видеоплеер с разбором терминов и WebGL-мини-игра (подброс монеты).

## 2. Technology Stack

- React 19 + TypeScript (strict mode)
- react-router v7
- Vite
- Ванильный JavaScript (ES2020+) для embeddable-модулей (видеоплеер, мини-игра)
- WebGL 2.0 + GLSL ES 3.00

Каждый урок (`lesson_1`, `lesson_2`, ...) — самостоятельный набор данных с одинаковой структурой.

## 4. Core Architecture Principles

- **Embeddable Module Interface** — все ванильные модули реализуют единый контракт:
  `{ init(container: HTMLElement, config: any): void; destroy(): void }`.
- **JSON-Driven Content** — вся структура и контент страницы описываются через JSON.
  Ассеты передаются исключительно как относительные пути (строки), не как импортируемые файлы.
- **Module Isolation** — React-компоненты не содержат логики ванильных модулей и не импортируют
  их внутренние зависимости. Интеграция происходит только через React-обёртки, вызывающие
  `init`/`destroy` embeddable-модуля.

## 5. Data Formats

Файлы данных урока ссылаются друг на друга по относительным путям:

- **config.json** — корневой файл урока, массив секций (`type`-based). Разные типы секций
  ссылаются на внешние ресурсы:
  - секция `playlist` → `playlist[].src` (видеофайлы)
  - секция `clipslesson` → `clipslesson.sourceVideo` (видео) и `clipslesson.terms` (путь к `terms.json`)
  - секция `dialogues` → `lines` (путь к `script.txt`)
  - секция `coingame` → монетка конфигурируется отдельным модулем (см. `coin.json`), путь к
    конфигу не хранится в `config.json`
  - остальные типы секций (`header`, `text`) — статический контент лендинга с путями на изображения

- **terms.json** — данные для модуля Video Player. Состоит из двух массивов:
  - `sequences[]` — таймкоды (`start`/`end`) отрезков видео, привязанные к `sequence`
  - `terms[]` — карточки терминов, привязанные к `sequence` (несколько терминов на один sequence),
    с полем `stillframe` (таймкод кадра) и опциональным `image`

- **coin.json** — конфигурация для WebGL-модуля Coin Game: `texture` (спрайт монеты),
  `radius`, `coordinates` (координаты heads/tails/edge на текстуре), `sound`, `chrono`
  (таймкоды анимации броска).

- **script.txt** — построчный диалог сцены в формате `SPEAKER_ID|text`. `SPEAKER_ID` соответствует
  полю `id` в секции `tiles` (`contentType: "tiles"`) внутри `config.json`, где описаны персонажи.

## 6. AI Skills

Проект использует три скилла в `.claude/commands/`:

- `/skill-layout` — верстка лендинга (React 19)
- `/skill-video-player` — видеоплеер с терминами (ванильный JS)
- `/skill-coin-game` — WebGL-монетка

При работе над конкретным модулем вызывай соответствующий скилл.

## 7. Important Constraints

- Ассеты (видео, аудио, изображения) не загружаются в контекст AI. Работаем только с путями (строками).
- Никогда не загружай в контекст содержимое `node_modules`, `package-lock.json` или `yarn.lock`.
- На момент разработки медиа-файлы отсутствуют в проекте. Пути в JSON могут указывать на
  несуществующие файлы — это нормально. AI-скиллы не должны проверять существование файлов.
- Ассеты будут добавлены в проект позже, после завершения работы над кодом.
- Модули изолированы: ванильные embeddable-модули не импортируют React.
- TypeScript strict mode.
- Все пути в JSON относительные (`../common/...` или `./...`).
- Не читай файлы в папках /node_modules и файлы package.json или yarn.lock
